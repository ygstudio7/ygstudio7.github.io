# 리눅스 파일 내용 검색: find, grep



리눅스에서는 자체 명령어를 사용하여 파일 내용을 검색할 수 있다. 

먼저, 검색하고자 하는 폴더로 이동한다. 하위 폴더를 포함하여 원하는 내용을 검색할 수 있다. 



### grep

파일 내에서 또는 입력값에서 특정 패턴을 검색한다.

|      | 설명                                              |
| ---- | ------------------------------------------------- |
| -v   | 일치되는 내용이 없는 라인을 표시한다.             |
| -c   | 일치되는내용의 행의 개수를 표시한다.              |
| -l   | 일치되는 내용의 파일명을 표시한다.                |
| -h   | 일치되는 내용을 찾은 파일이름을 표시하지 않는다.  |
| -n   | 일치되는 내용이 있는 행은 행번호와 함께 표시한다. |
| -r   | 하위 폴더까지 검색한다.                           |



사용방법:

```bash
grep -r "찾을 내용" ./*
```

# find | grep



find와 grep을 함께 사용하면, find의 결과를 grep의 입력으로 넣을 수 있다. 

이것을 **파이프**라고 부르며, 프로그램의 실행결과를 다른 프로그램의 입력으로 연결한다.

사용방법 1: 아래는 find로 원하는 파일들을 찾은 후, 그 파일들내에서 grep으로 찾을 문자열을 검색한다.

```bash
find [경로] -name "파일명" | xargs grep "찾을 문자열"
```



예:

```bash
$ find ./ -name "*.cpp" | xargs grep "ClassVisitor"
./src/V3Class.cpp:class ClassVisitor final : public AstNVisitor {
./src/V3Class.cpp:    explicit ClassVisitor(AstNetlist* nodep) { iterate(nodep); }
./src/V3Class.cpp:    virtual ~ClassVisitor() override {
./src/V3Class.cpp:    { ClassVisitor visitor(nodep); }  // Destruct before checking
```



사용방법 2: 검색된 문자의 색을 다르게 표시하고 싶을때

```bash
find [경로] -name "파일명" | xargs grep -color=auto "찾을 문자열"
```
