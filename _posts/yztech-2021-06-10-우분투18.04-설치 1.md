### 문제 해결

신규 PC에 장착된 r8125의 경우, driver가 없어서 초기 설치치 네트워크 이슈가 있는 경우가 있다.

특히 Ubuntu 18.04를 설치할 때, 다음과 같은 오류가 발생하는 경우에는 Ubuntu 21.04를 설치햐면 쉽게 해결할 수 있다. realtek r8125, r8169의 경우 kernel 5.6까지만 지원하므로, 그 이상의 kernel 버전인 ubuntu 20.04 LTS의 경우에는 네트워크가 잡하지 않아서, 설치 진행이 어렵다. 따라서, ubuntu 21.04를 설치해서 진행하는게 가장 수월하다.

```
r8169 unknown chip XID 641
```



Ubuntu 18.04를 그대로 설치해야 하는 경우에는, 휴대폰 USB 테더링을 사용하여, 인터넷을 공유하면 네트워크 사용이 가능하다.

![image-20210610185820346](e:\_ygkim\_Doc\_future\\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-06-10-우분투18.04-설치 1.assets\image-20210610185820346.png)



realtek 홈페이지에 들어가서, 가장 하단의 r8125 리눅스 드라이버를 받는다.

https://www.realtek.com/en/component/zoo/category/network-interface-controllers-10-100-1000m-gigabit-ethernet-pci-express-software

![image-20210610192619143](e:\_ygkim\_Doc\_future\\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-06-10-우분투18.04-설치 1.assets\image-20210610192619143.png)



아래와 같이 터미널에서 upate를 진행한후, 받은 드라이버가 포함된 r8125로 시작하는 폴더에 들어가서 autorun.sh를 실행하면 네트워크를 정상적으로 사용할 수 있게 된다.

```bash
sudo apt update
cd r8125-xxxx
sudo ./autorun.sh
```
