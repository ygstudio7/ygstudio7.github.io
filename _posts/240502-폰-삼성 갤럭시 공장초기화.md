# 갤럭시 공장 초기화 버튼



1. Ensure the device is powered off.

   If the device is responsive and can be powered on, the [preferred reset method](https://www.verizon.com/support/knowledge-base-300278/) should be performed.

2. Simultaneously press and hold the 

   Volume up

    and 

   side buttons

    until the device vibrates and the Galaxy A03s screen appears then release all buttons.

   Allow up to 30 seconds for the recovery screen to appear.

   ![Power and Volume Up buttons](https://ss7.vzw.com/is/image/verizondsc/power_volume_up_buttons-4)

3. From the Android Recovery screen, select 

   Wipe data / factory reset

   .

   Utilize the volume buttons to cycle through the available options and the side button to select.

   ![Android system recovery screen with wipe data / factory reset](https://ss7.vzw.com/is/image/verizondsc/android_system_recovery_01-7)

4. Select 

   Factory data reset

   .

   Allow several seconds for the factory data reset to complete.

   ![Android system recovery screen with Yes](https://ss7.vzw.com/is/image/verizondsc/android_system_recovery_02-7)

5. Select 

   Reboot system now

   .

   Allow several minutes for the reboot process to complete.

   If applicable, [set up your device](https://www.verizon.com/support/knowledge-base-300237/).

   ![Android system recovery screen with reboot system now](https://ss7.vzw.com/is/image/verizondsc/android_system_recovery_03-7)
