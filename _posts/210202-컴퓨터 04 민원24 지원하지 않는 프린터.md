# 해결방법1 

markany 홈페이지의 고객지원 페이지에서 프린터 업데이트를 실행한다 [2] .



![image-20210202215047178](e:\_ygkim\_Doc\_future\\_work\github pages\ygstudio7\ygstudio7.github.io\images\image-20210202215047178.png)





# 해결방법2

위의 방법으로 되지 않는 경우, markany 지원 프린터 목록을 확인해서, 비슷한 프린터를 찾는다 [1].  

본인의 경우, 한국에서 판매하지 않고 미국에서 판매하는 MF634CDW를 사용중이기 때문에, 한국에서 판매중인 비슷한 모델인 MF620C을 찾아서 사용하였다. 

![image-20210202214828017](e:\_ygkim\_Doc\_future\\_work\github pages\ygstudio7\ygstudio7.github.io\images\image-20210202214828017.png)



## 레지스트리 수정

![open regedit in Windows](https://www.thewordcracker.com/wp-content/uploads/2015/03/open-regedit-in-Windows.jpg)



regedit를 실행하여, 아래와 같이 프린터 설정 정보들을 찾는다.

아래와 같이 두군데를 수정한다.

**HKEY_LOCAL_MACHINE -> SYSTEM -> CurrentControlSet -> Control -> Print -> Printers**

![image-20210202215351309](e:\_ygkim\_Doc\_future\\_work\github pages\ygstudio7\ygstudio7.github.io\images\image-20210202215351309.png)



![image-20210202215413549](e:\_ygkim\_Doc\_future\\_work\github pages\ygstudio7\ygstudio7.github.io\images\image-20210202215413549.png)



아래와 같이 MF620C로 인식되어 정상적으로 출력된다.

프린터명, 프린터 드라이버, 모델명을 모두 맞춰야 동작하는 것으로 생각된다.
