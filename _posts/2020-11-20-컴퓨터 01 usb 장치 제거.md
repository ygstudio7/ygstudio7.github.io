# '이 장치는 현재 사용 중입니다' 오류를 수정하고 USB 대용량 저장소를 안전하게 제거하는 방법

![img](https://images.easeus.com/images/en/icon/yvette.jpg) Yvette | [미디어 저장장치 복구하기](https://www.easeus.co.kr/storage-media-recovery/) | 2020-09-29

- 개요:

  이 페이지에서는 'USB 대용량 저장 장치를 꺼내는 데 문제가 있습니다.이 장치는 현재 사용 중입니다. 장치를 사용하고 있을 수 있는 모든 프로그램이나 창을 닫은 다음 다시 시도하십시오.'라는 오류 메시지에 대한 해결 방법에 대해 설명합니다. 컴퓨터에서 USB 또는 외장 하드 드라이브를 안전하게 제거하려고 할 때 또한 안전하지 않은 플러그를 뽑은 후 USB 장치에서 영구적 인 데이터 손실을 방지하려면 EaseUS 데이터 복구 마법사를 사용하여 즉시 복구하십시오.

## Windows 7 / Windows 10에서 외장 USB 드라이브를 꺼내는 데 문제가 있습니다

*USB 대용량 저장 장치 꺼내기 문제*

*"이 장치는 현재 사용 중입니다. 장치를 사용하고있을 수있는 모든 프로그램이나 창을 닫은 다음 다시 시도하십시오."*

![장치를 갑자기 못 꺼낼때](https://www.easeus.co.kr/images/drw/screenshot/this-device-is-currently-in-use.png)







## "장치가 현재 사용 중"을 수정하고 USB 대용량 저장 장치를 안전하게 제거하는 방법?

로그 아웃 및 시스템 로그온을 포함한 통합 접근 방식을 시도한 경우 시스템을 한두 번 다시 시작했지만 여전히 오류를 제거하지 못했습니다.

USB 리소스를 차지하는 실제 프로그램을 비활성화하기 위해 다른 세 단계를 수행해 보겠습니다.

**1 단계.** 작업 관리자에서 현재 USB 장치를 사용중인 애플리케이션을 찾습니다.

작업 관리자를 불러 오려면 **"Ctrl + Alt + Del"**키를 누르십시오.

작업 관리자에 액세스하고 프로세스 탭에서 USB 장치를 사용하는 응용 프로그램을 찾습니다.

선택한 응용 프로그램을 마우스 오른쪽 버튼으로 클릭하고 **"작업 종료"**를 선택합니다.

![프로세스 작업 종료](https://www.easeus.co.kr/images/drw/screenshot/process-end-task-1.png)

**2 단계.** 디스크 관리에서 USB 꺼내기

"내 컴퓨터"(Windows 7) 또는 "내 PC"(Windows 10)를 우클릭하고 관리를 클릭합니다.

저장소에서 디스크 관리를 클릭합니다.

제거 할 USB 장치를 찾아 마우스 오른쪽 단추로 클릭하고 꺼내기를 클릭합니다. (참고-디스크 관리에서 연결을 끊을 외장 하드 드라이브 인 경우 "오프라인"옵션이 표시됩니다. 다음에 사용할 드라이브를 컴퓨터에 다시 넣으면 다음으로 돌아 가야합니다. 디스크 관리를 열고 "온라인"상태로 전환하십시오.)

![디스크 관리에서 장치 꺼내기](https://www.easeus.co.kr/images/drw/screenshot/eject-hard-drive-disk-management.png)

**3 단계.** 장치 관리자에서 USB 꺼내기

"내 컴퓨터"(Windows 7) 또는 "내 PC"(Windows 10)를 우클릭하고 관리를 클릭합니다.

장치 관리자를 클릭하고 **범용 직렬 버스 컨트롤러**를 클릭합니다.

관련 장치를 찾아 우클릭하여 제거합니다.

![장치를 지우기](https://www.easeus.co.kr/images/drw/screenshot/uninstall-usb-hub.png)

##  기타 "USB 대용량 저장 장치 꺼내기 문제"관련 오류 ...

- 윈도우는 '일반 볼륨'장치가 사용 중이므로 중지 할 수 없습니다. 장치를 사용하고있을 수있는 프로그램이나 창을 닫고 나중에 다시 시도하십시오.
- 지금은 '일반 볼륨'장치를 중지 할 수 없습니다. 나중에 다시 장치를 중지하십시오.
- Windows에서 'USB 연결 SCSI (UAS) 대용량 저장 장치'장치를 중지 할 수 없습니다. 이 장치가 아직 사용 중일 때는 제거하지 마십시오. 이 장치를 사용하는 모든 프로그램을 닫은 다음 제거하십시오.

이 페이지에서 제공하는 모든 솔루션은 여기에있는 다른 세 가지 유사한 USB 꺼내기 문제에도 적용 할 수 있습니다.
