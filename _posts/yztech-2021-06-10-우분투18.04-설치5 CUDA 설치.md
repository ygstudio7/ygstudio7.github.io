# GUI 기반 Nvidia driver 설치

NVIDIA 드라이버를 가장 쉽게 설치하는 방법은, `Activies` 에서 `driver`를 입력하면, 아래와 같이 `Software & Updates` 창을 열수 있다. 이후 `Additional Driver`탭에 들어가면 NVIDIA 관련 모든 driver 들을 확인할 수 있다.

우측 하단의 `Apply Changes`를 선택하면, 몇분동안 설치가 진행되고, `reboot`후에는 nvidia 드라이버가 정상 동작한다.

nvidia-settings을 열어서, 필요한 설정을 진행할 수 있다.

```bash
sudo nvidia-settings
```

# CLI 기반 Nvidia driver 설치

terminal에서도 Nvidia driver를 설치할 수 있다.

```bash
ubuntu-drivers devices
```



아래와 같이 drivers들이 보이고, 이중에서 `recommended` 드라이버를 설치하면 된다.

```
== /sys/devices/pci0000:00/0000:00:01.0/0000:01:00.0 ==
modalias : pci:v000010DEd00002206sv0000103Csd000088D7bc03sc00i00
vendor   : NVIDIA Corporation
driver   : nvidia-driver-465 - third-party non-free recommended
driver   : nvidia-driver-460-server - distro non-free
driver   : nvidia-driver-455 - third-party non-free
driver   : nvidia-driver-460 - third-party non-free
driver   : xserver-xorg-video-nouveau - distro free builtin
```



```bash
sudo apt install nvidia-driver-465
```



```bash
sudo reboot
```
