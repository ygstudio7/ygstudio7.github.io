# Ubuntu 21.04 설치 후 작업



### 시스템 업데이트

업데이트를 진행하여 시스템을 최신 상태로 유지한다.

```bash
sudo apt update
sudo apt upgrade
```



ifconfig등을 사용할 수 있도록 net-tools 등 필요한 도구 설치한다.

```
sudo apt install net-tools
```



### ssh 설치

ssh 접속을 위한 패키지를 설치한다. 

아래 명령을 수행하여, openssh-server가 설치되어 있는지 확인하면 된다. 

```bash
dpkg -l | grep ssh
```

openssh-server가 설치되지 않은 경우, 아래와 같이 설치를 진행한다.

```bash
sudo apt install openssh-server
```

제대로 동작하는지 확인한다.

```bash
service ssh status
```

동작하지 않는 경우 ssh 서비스를 시작한다.

```bash
service ssh start
```

### samba 설치

윈도우 시스템과 파일 공유 및 전송을 위한 samba 패키지를 설치한다. 

```bash
sudo apt install samba
```



환경 설정한다.

```bash
sudo smbpasswd -a usr
sudo nano /etc/samba/smb.conf
```



아래와 같이 환경 설정 내용을 추가한다. 이떄 `path`에는 공유할 위치를 기입하고, `valid users`에는 위에서 설정한 samba userid를 넣으면 된다.

```
[shared]
    path = /media/data
    valid users = usr
    writeable = yes
```



```
sudo service smbd restart
```
