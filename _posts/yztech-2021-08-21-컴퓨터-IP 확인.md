# 윈도우에서 공유 드라이브의 IP 주소 확인하기

네트워크 공유는 UNC 경로 (`\\`)를 사용하여 접근할 수 있다. 자주 사용되는 공유 드라이브는 윈도우상에서 문자를 사용하여 매핑할 수 있다. 만약 이미 연결된 공유 드라이브의 IP를 얻어야할 경우, 본 post는 구하는 방법을 알려준다. 



네트워크 드라이브 `\\media`를 `hdd`이름으로 `S:` 드라이브에 매핑했다고 하자. 파일 검색기에서 매핑된 드라이브 문자 `S:` 옆에 네트워크 드라이브 명이 보여진다.

![image-20210817105108112](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\images\image-20210817105108112.png)





매핑된 컴퓨터의 IP 주소를 얻기 위해서는, 명령 프롬프트 창을 열고 다음과 같이 입력한다. 이때 `-4`를 사용하지 않으면, IPv6 주소가 보여진다. 

```앤
C:\>ping media

Ping medla.local [ff80::f585:208c:f86e:f280%4] 32바이트 데이터 사용:
ff80::f585:208c:f86e:f280%4의 응답: 시간<1ms
ff80::f585:208c:f86e:f280%4의 응답: 시간=1ms
ff80::f585:208c:f86e:f280%4의 응답: 시간<1ms
ff80::f585:208c:f86e:f280%4의 응답: 시간<1ms

ff80::f585:208c:f86e:f280%4에 대한 Ping 통계:
    패킷: 보냄 = 4, 받음 = 4, 손실 = 0 (0% 손실),
왕복 시간(밀리초):
    최소 = 0ms, 최대 = 1ms, 평균 = 0ms
```



```dos
C:\>ping media -4

192.168.0.105의 응답: 바이트=32 시간<1ms TTL=64

왕복 시간(밀리초):
```

만약, 공유 폴더를 제공하는 컴퓨터 이름을 알고자 하는 경우 `net use` 명령을 사용한다. 

```dos
C:\>net use
새 연결 정보가 저장됩니다.

-------------------------------------------------------------------------------

OK           T:        \\dev					          Microsoft Windows Network
```
