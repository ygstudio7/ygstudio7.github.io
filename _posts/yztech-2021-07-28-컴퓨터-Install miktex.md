# How to install MikTex



To install a basic TeX/LaTeX, download and run the MikTex installer. 

Click the `Download` button on the download page (https://miktex.org/download), .

![image-20210728090531452](e:\_ygkim\_Doc\_future\\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-07-28-컴퓨터-Install miktex.assets\image-20210728090531452.png)





The install first shows the MikTex copying conditions.

![image-20210728090723385](e:\_ygkim\_Doc\_future\\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-07-28-컴퓨터-Install miktex.assets\image-20210728090723385.png)



Choose one between two installation scopes.

![image-20210728090753001](e:\_ygkim\_Doc\_future\\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-07-28-컴퓨터-Install miktex.assets\image-20210728090753001.png)



Choose a location for the installation directory.

![image-20210728090903867](e:\_ygkim\_Doc\_future\\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-07-28-컴퓨터-Install miktex.assets\image-20210728090903867.png)



Set your preferences.

![image-20210728090924427](e:\_ygkim\_Doc\_future\\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-07-28-컴퓨터-Install miktex.assets\image-20210728090924427.png)



The installation will take a few minutes. 

![image-20210728091038953](e:\_ygkim\_Doc\_future\\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-07-28-컴퓨터-Install miktex.assets\image-20210728091038953.png)



When the MikTeX is installed, the installer shows the completion page.
