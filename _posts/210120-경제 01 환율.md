# 환전 스프레드

미국 $/1000원이라고 가정



상황 1. $ 현찰 매입시 1020원 필요, $ 현찰 매도시 980원 받음.

이 경우 현찰매매에 대한 환전 스프레드가 20원이므로, 

현찰매매 환전 스프레드율 = 환전스프레드 / 환율 = 20 / 1000 = 2%



상황 2. $ 송금시 1010 원 필요, $ 받을시 990원 받음.

이 경우 전신환 매매에 대한 환전 스프레드가 10원이므로,

전신환 매매 환전 스프레드율 = 환전스프레드 / 환율 = 10 / 1000 = 1%



위에서 KEB하나은행의 경우, 

현찰 매매에 대한 환전스프레드 = 18.43원, 환전 스프레드율은 18.43 / 1099.2= 1.68%

전신환 매매에 대한 환전스프레드 = 9.9원, 환전 스프레드율은 9.9 / 1099.2 = 0.9%



# 환율 우대

환율 우대란 환전스프레드에 대한 할인율을 말한다.

환율 우대 90%  의 경우 

현찰 매매 환전스프레드 18.43원중 10% 만 받겠다.

1099.2 + (18.43 * 10 %) = 1099.2 + 1.843 = 1101 원

전신환매매 환전 스프레드 9.9원중 10% 만 받겠다. 1원에 해당

1099.2 + (9.9 *10%) = 1100원
