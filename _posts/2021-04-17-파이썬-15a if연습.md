## 문제1: if 구문을 활용하여 등급 출력하기

다음과 같이 점수를 받아서, 등급을 출력하는 프로그램을 작성한다.

| score        | grade |
| ------------ | ----- |
| 90<= s < 100 | A     |
| 80<= s < 90  | B     |
| 70<= s < 80  | C     |
| 60<= s <70   | D     |
| 0<= s < 60   | F     |



실행 과정

```
> Input your score: 95
Your grade is: A
> Input your score: 30
Your grade is: F
```



사용자 입력을 위해 input함수를 사용한다.

if/elif/else 구문을 사용한다.

가능한 이해도가 높은 간결한 코드를 작성하려고 노력한다.  > 재활용성 up



### 기본 코드

(1) input함수를 사용하면 인자로 받은 "Input your score:"를 출력하고, 입력을 기다린다. 입력된 값은 문자열로서 int()함수를  사용하여 정수형으로 변환한다.

(3) score가 90이상이면 변수 grade에는 "A"를 설정한다.

(6) print()함수를 사용하여 결과를 출력한다.

```python
score = int(input("Input your score:"))
if(score>=90):
    grade = "A"

# code here

print("Your grade is " + grade)
```



위 코드를 실행한 후 결과를 확인해보고, 중간에 필요한 코드를 구현한다. 



일반적인 코드는 다음과 같은 구조를 가지고 있다. 보통의 프로그램들은 입력을 받고, 연산한 후, 결과를 출력하는 3단계를 거친다. 

위에서도 (1)입력을 받고, (2-3) 연산후 (7) 출력하는 3단계를 거친다.

```python
step1: 입력 받기
  
step2: 입력을 가지고 연산하기
  
step3: 결과 출력하기
  
```



### 코드 2

if/elif를 사용하여 연속된 비교문을 만들 수 있다. 

```python
score = int(input("Input your score:"))

if(score>=90):
    grade = "A"
elif(score>=80):
    grade = "B"
elif(score>=70):
    grade = "C"
elif(score>=60):
    grade = "D"
else:
    grade = "F"

print("Your grade is " + grade)
```
