Windows에서 GCC를 설치하고 VS Code에서 사용하는 방법을 단계별로 설명해 줄게요.

------

## **1. MinGW-w64 설치 (GCC 포함)**

Windows에서는 기본적으로 GCC가 설치되어 있지 않으므로, **MinGW-w64**를 사용하여 설치합니다.

### **(1) MinGW-w64 다운로드 및 설치**

1. [MinGW-w64 다운로드 페이지](https://winlibs.com/)로 이동합니다.

2. "Mingw-w64 GCC" 최신 버전을 다운로드합니다.

   - 보통 **"UCRT Runtime + Winlibs"** 버전을 추천합니다.
   - "x86_64-posix-seh" 또는 "x86_64-win32-seh" 버전을 선택하세요.

   ![image-20250331102038255](assets/image-20250331102038255.png)

3. 다운로드한 압축 파일을 적절한 위치(예: `C:\mingw-w64`)에 풀어놓습니다.





### **(2) 환경 변수 설정**

1. **"시스템 속성"** 열기 (`Win + R` → `sysdm.cpl` → **Enter**)
2. **"고급"** 탭 → **"환경 변수"** 버튼 클릭
3. **"시스템 변수"** 목록에서 `Path`를 찾아 편집
4. **새로 만들기** 클릭 → `C:\mingw-w64\bin` (설치 경로에 따라 다를 수 있음) 추가
5. **확인** → **컴퓨터 재부팅**

### **(3) 설치 확인**

- **명령 프롬프트(CMD) 열기** (`Win + R` → `cmd` → **Enter**)

- 다음 명령어 입력 후 실행:

  ```sh
  gcc --version
  ```

- GCC 버전이 출력되면 설치 성공!

------

## **2. VS Code에서 GCC 사용 설정**

### **(1) VS Code 설치**

- [VS Code 공식 사이트](https://code.visualstudio.com/)에서 다운로드하여 설치합니다.

### **(2) C/C++ 확장팩 설치**

1. VS Code 실행
2. **확장(Extensions) 탭** (`Ctrl + Shift + X`)
3. **"C/C++"** 검색 후 **"C/C++ by Microsoft"** 설치

### **(3) 빌드 및 실행 설정**

1. **"파일" → "폴더 열기"** (예: `C:\Projects\C_Program`)

2. `main.c` 파일을 만들고 간단한 코드 작성:

   ```c
   #include <stdio.h>
   
   int main() {
       printf("Hello, GCC on VS Code!\n");
       return 0;
   }
   ```

3. **"터미널" → "새 터미널"** (`Ctrl + ~`)

4. 컴파일 후 실행:

   ```sh
   gcc main.c -o main.exe
   ./main.exe
   ```

------

## **3. (선택) VS Code에서 자동 빌드 설정**

### **(1) tasks.json 설정**

1. **"Ctrl + Shift + P"** → **"Tasks: Configure Tasks"** 입력 후 선택

2. `tasks.json` 파일에서 다음과 같이 설정:

   ```json
   {
       "version": "2.0.0",
       "tasks": [
           {
               "label": "Build C Program",
               "type": "shell",
               "command": "gcc",
               "args": ["main.c", "-o", "main.exe"],
               "group": {
                   "kind": "build",
                   "isDefault": true
               }
           }
       ]
   }
   ```

3. 빌드 실행: **"Ctrl + Shift + B"** → 자동 컴파일

------

이제 Windows에서 GCC를 사용하여 VS Code에서 C 프로그램을 컴파일하고 실행할 수 있습니다! 🚀
