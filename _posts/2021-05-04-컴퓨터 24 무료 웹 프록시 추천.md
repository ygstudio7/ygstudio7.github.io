# socks5 프록시

참고: https://m.blog.naver.com/any9122/221865812776

SOCKS (Socket Secure) 는 프록시 서버를 통해 클라이언트와 서버간의 네트워크 패킷을 교환하는 인터넷 프로토콜이다.

실제로 SOCKS 서버는 TCP 연결을 임의의 IP 주소의 프로시하고 UDP 패킷을 전달하는 방법을 제공한다.

SOCKS는 여러 버전이 있지만, SOCKS5는 네트워크 트래픽 유형을 구별할 수 없기 때문에 가장 유연한 서버 프로토콜로 볼 수 있다. 토렌트의 FTP, 웹 브라우저의 HTTP, 이메일의 SMTP 가 여기에 해당한다.
