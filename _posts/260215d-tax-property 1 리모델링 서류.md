# ⭐ 가장 중요한 것 (CPA가 실제로 보는 기준)

CPA/IRS는 이렇게 판단합니다:

`1. 작업이 실제 있었는가? 2. 금액이 합리적인가? 3. 임대 전 완료되었는가?`

당신 케이스:

- 욕실 전체 리모델링 ✔
    
- rental 이전 ✔
    
- 계약서 존재 ✔
    

👉 **Capital improvement 인정 가능성 매우 높음**

# ✅ 3️⃣ 지금 당신이 해야 할 BEST PRACTICE

가능하면 아래를 모아 하나의 PDF로 만드세요:

## “Remodel Support File”

포함:

1️⃣ 계약서 (필수)  
2️⃣ 결제 증빙 (bank/credit card)  
3️⃣ 공사 날짜 확인 가능한 메시지  
4️⃣ 공사 사진 (있으면 매우 좋음)

`Property1_Bathroom_Remodel_2025_Support.pdf`
