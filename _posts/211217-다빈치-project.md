# autosave on

자동 저장 기능을 켜기위해서는, 

좌측 상단 메뉴에서, DaVinci Resolve를 선택후, Preferences를 선택합니다.

![image-20211217141732935](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-12-17-다빈치-project.assets\image-20211217141732935.png)



상단의 User 탭을 누른후, 좌측에서 Project Save and Load를 선택합니다.

그림과 같이 Save Settings에서 [v] Live Save를 선택하면, 프로젝트 진행중에 멈추더라도 모든 상태가 자동으로 저장됩니다.

[v] Project backups을 선택하면, 프로젝트들을 분, 시간, 날짜에 맞춰서 설정한 폴더에 자동으로 백업이 가능합니다.

![image-20211217142247137](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-12-17-다빈치-project.assets\image-20211217142247137.png)



# Disk Database

현재 프로젝트에서 사용되는 폴더를 확인하기 위해서는, 

프로그램 우측 하단의 홈 버튼을 누른다.

![image-20211217150331394](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-12-17-다빈치-project.assets\image-20211217150331394.png)



아래 그림과 같이 상단의 info 버튼을 누르면, Local Database 에서 Location 위치가 보여준다.

Local Database에서 우측 마우스 버튼을 누르면, 

Open File Location 메뉴가 나오고, 프로젝트 폴더가 열린다.

![image-20211217150442000](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-12-17-다빈치-project.assets\image-20211217150442000.png)



기존의 프로젝트들을 이곳에 옮기면 그대로 사용할 수 있다.
