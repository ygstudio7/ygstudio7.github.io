만약, 설치가 진행되지 않는 경우, 크롬에서 다운로드 폴더를 확인한 후 터미널에서 직접 실행하면 됩니다.

크롬에서 다운로드는 보통 `Home/Downloads`로 들어가게 됩니다.

따라서, 터미널에서 다음과 같이 위 deb 파일을 설치하면 됩니다.

```bash
sudo apt install ./chrome-reomte-desktop_current_amd64.deb
```



크롬 원격 데스크톱이 동작할 수 있도록 아래와 같이 설정 폴더를 생성합니다.

```bash
mkdir ~/.config/chrome-remote-desktop
```



크롬을 모두 닫은 뒤, 다시 실행한 후 remotedesktop.google.com으로 들어갑니다.
