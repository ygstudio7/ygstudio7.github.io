

# 파이썬 에디터

파이썬 대화형 인터프리터는 실행해서 간단한 코드들을 확인하는 데 편리하다.

파이썬 에디터는 소스 코드를 편집 저장하고 실행하는 통합 개발환경으로서, 파이썬을 설치하면 기본으로 IDLE 에디터가 같이 설치된다. 



![image-20210312091242356](e:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\images\image-20210312091242356.png)



파이썬 IDLE 에디터는 두가지 창으로 구성된다. 

- Shell window: 실행 결과 표시, 셀과 동일 기능 수행, IDLE 실행시 출력됨
- Editor window: 코드 편집창



File > New File 을 선택한다.

![image-20210312091602290](e:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\images\image-20210312091602290.png)



아래와 같이 빈 editor window가 나타난다.

![image-20210312091647374](e:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\images\image-20210312091647374.png)





가장 간단한 프로그램을인 "Hello, world" 출력 코드를 작성해보자.

`#`은 한줄 주석이고, 여러 라인 주석을 만들경우 `"""` 을 사용한다.

```python
# hello.py

print("Hello, world")
```



[Run > Run Module] 을 실행해보자. Matlab과 같이 `F5`를 눌러도 동일하게 실행할 수 있다.

# 파이썬 에디터 추천

피이썬으로 프로그램을 작성할 때는, 위에서 소개한 IDLE 에디터보다 많은 기능을 갖춘 에디터를 사용하는게 편리하다. Visual studio code나 PyCharm 에디터를 추천한다. 여기에서는 파이썬 전용 에디터은 PyCharm을 설치해보자.

- visual studio code
- PyCharm



### Visual Studio Code

파이썬 전용 에이터가 아니지만, 다양한 언어를 지원한다. 공식 사이트 ([https://code.visualstudio.com](https://code.visualstudio.com/))에서 다운로드 가능하다.

사용시에는 Extension 메뉴에서 파이썬 Extenstion을 설치한다.



### PyCharm

파이썬 전용 에디터로, 코드 자동 완성, 문법 체크 등 편리한 기능을 많이 제공한다. 공식 사이트 ([http://www.jetbrains.com/pycharm/download](http://www.jetbrains.com/pycharm/download/)) 에서 다운로드 할 수 있다.

무료 설치가능한 Community 를 받아서 설치한다.
