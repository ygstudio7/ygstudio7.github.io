관련 항목들을 알아보면,

[v] Git LFS (Large File Support): 대용량 파일을 지원할지 여부를 체크하는 것으로, 기본 설정에 포함되어 있다.

[v] Associate .git* configration files with the default text editor: git 구성 파일을 기본 텍스트 편집기와 연결시키는 것으로, 기본 설정에 포함되어 있다.

[v] Associate .sh files to be run with Bash: 확장자 .sh파일을 Bash와 연결하는 것으로, 기본설정에 포함되어 있다.

[ ] Check daily for Git for Windows updates: 윈도우 업데이트를 위해 Git을 매일 확인하는 것으로, 기본 설정은 아니다.

Git 저장소 체크인, 체크아웃할때 줄바꿈 옵션을 선택한다. 기본설정은 윈도우 스타일로 체크 아웃하고, Unix 스타일로 커밋하는 것이다. 

![image-20211013112743596](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-10-13-컴퓨터-윈도우 10 git 설치.assets\image-20211013112743596.png)



운영체제에 따라 줄바꿈 값이 다르다. 줄바꿈시, 윈도우에서는 `\r\n`을 사용하고, 유닉스에서는 `\n`만 사용한다. 

`\r`은 carriage return (CR) 으로, 화면, 혹은 파일에서 커서를 다음 라인으로 넘긴다.

`\n`은 line feed (LF) 로, 화면 혹은 파일에서 커서를 현재 라인의 맨처음으로 옮긴다.

윈도우에서는 CRLF를 해야 커서를 다음라인으로 넘긴후, 라인 시작으로 옮겨지나,

유닉스에서는 LF만 해도 커서가 다음라인의 시작으로 넘어간다.



관련 옵션은 아래와 같다.

[v] Checkout Windows-style, commit Unit-style line endings: 체크아웃은 윈도우 스타일로, 커밋은 유닉스 스타일로 변경한다.

[ ] Checkout as-is, commit Unit-style line eidings: 체크아웃은 그대로, 커밋만 유닉스 스타일로 변경한다.

[ ] Checkout as-is, commit as-is: 체크아웃, 커밋시 스타일을 변환하지 않는다.

# 사용자 등록 및 확인

버전 확인

```bash
git --version
```

```
git version 2.33.0.windows.2
```



사용자 등록

```bash
git config --global user.name "test" 
git config --global user.email "test@gmail.com"
```



확인

```bash
git config --list
```



위와 같이 Git 설치 및 기본 설정이 완료되었다.
