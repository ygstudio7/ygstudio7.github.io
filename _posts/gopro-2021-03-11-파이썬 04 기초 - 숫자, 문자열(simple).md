# 기초



자료형은 숫자, 문자열 등 프로그램 상에서 자료 형태로 표현하는 모든 것을 뜻한다. 



프로그래밍 언어를 이해하는 전통적인 방법은, 그 언어의 자료형을 이해하는 것이었다. 

90년대부터 C언어가 대중화되면서, char, int, float, double 과 같은 자료형들을 먼저 이해해야 했고,

16, 32, 64 bits 컴퓨터들이 생겨나면서, 각 컴퓨터들이 기본적으로 몇 bits까지 처리하는지, 처리할 수 있는 숮자의 범위는 얼마나 되는지를 알고 프로그램을 구현하는게 마치 프로그래밍을 이해하는 첫걸음처럼 생각되었다. 

하지만, C언어 이전의 80년대에 사용된 간단한 Basic과 같은 언어들은 그러한 자료형들이 큰 의미가 없었고, 

최근의 고급언어들인 Python, Scala와 같은 언어들에서도 그러한 자료형들을 구분하는게 큰 의미가 없어졌다. 



따라서, 이젠 자료형을 이해하는 것은 단지 숫자를 표시하기 위한 숫자형, 문자를 표시하기 위한 문자형 정도만 알아도, 프로그래밍을 시작하기엔 충분할 것으로 생각된다. 





# 숫자형



숫자형(Number)이란 숫자 형태로 이루어진 자료형으로, 우리가 사용하는 숫자를 표현하기 위해 사용되는 것을 말한다. 

우리가 흔히 사용하는 123 같은 정수, 12.34 같은 실수가 가장 흔한 숫자형이 될 수 있다.

또한, 컴퓨터가 이러한 자료형을 실제로 기억하는 방법인 2진수도 될 수 있다. 

또한, 이를 사람들이 좀더 이해하기 편한 형태로 표현하는 8진수나 16진수 같은 것도 있다.



다음 표는 파이썬에서 숫자를 어떻게 사용하는지 간략하게 보여 준다.

| 항목   | 사용 예                 |
| :----- | :---------------------- |
| 정수   | 123, -345, 0            |
| 실수   | 123.45, -1234.5, 3.4e10 |
| 8진수  | 0o34, 0o25              |
| 16진수 | 0x2A, 0xFF              |

이제 이런 숫자를 파이썬에서는 어떻게 만들고 사용하는지 자세히 알아보자.



### 정수 표현

정수형(Integer)이란 말 그대로 정수를 뜻하는 자료형을 말한다. 다음 예는 양의 정수와 음의 정수, 숫자 0을 변수 a에 대입하는 예이다.

```python
>>> a = 123
>>> a = -178
>>> a = 0
```



### 실수 표현

파이썬에서 실수형(Floating-point)은 소수점이 포함된 숫자를 말한다. 다음은 실수를 변수 a에 대입하는 예이다.

```python
>>> a = 1.2
>>> a = -3.45
```



### 사칙연산: `+`, `-`, `*`, `/` 연산자

숫자형은 기본적으로 사칙연산을 지원하고 `+`, `-`, `*`, `/` 연산자를 사용하여 표시한다.

```python
>>> a = 3
>>> b = 4
>>> a + b
7
>>> a * b
12
>>> a / b
0.75
```



### 제곱: `**`  연산자

`**`연산자는 $x^y$를 파이썬에서 표시할때 사용한다. 

```python
>>> a = 3
>>> b = 4
>>> a ** b
81
```



### 나머지:  `%` 연산자

'%' 연산자는 나눗셈후 나머지를 반환한다.

아래 코드에서 7을 3으로 나누면 나머지는 1을 반환하고, 3을 7로 나눈 나머지 3을 반환한다.

```
>>> 7 % 3
1
>>> 3 % 7
3
```



### 몫: `//` 연산자

`/` 연산자는 7 나누기 4를 수행하고 그 값  1.75을 반환하지만, `//`은 몫 1을 반환한다. 

```python
>>> 7 / 4
1.75
>>> 7 // 4
1
```





# 문자형

문자열(String)이란 사칙연산들 수행하는 숫자형과 달리 문자로 구성된 문자들의 집합을 의미한다. 예를 들어 다음과 같은 것들이 문자열이다.

```python
"Life is too short, You need Python"
"a"
"123"
```

위 문자열 예문을 보면 모두 큰따옴표(" ")로 둘러싸여 있다. "123은 숫자인데 왜 문자열이지?"라는 의문이 드는 독자도 있을 것이다. 따옴표로 둘러싸여 있으면 모두 문자열이라고 보면 된다.



파이썬에서는 큰 따옴표와 작은 따옴표를 사용하여 문자열을 표시할 수 있다. 

```python
"Hello World"
'Python is fun'
```



파이썬에서는 문자열 처리를 위한 여러 연산자들을 제공한다. 이러한 연산자들이 편리하기도 하지만, 때로는 다른 언어들과 사용법이 달라서 혼동을 일으키키도 하는 단점도 있다. 

### 문자열 연결 (Concatenation): `+` 연산자

파이썬에서는 문자열을 연결할 수 있는 `+` 연산자를 제공한다. 

```python
>>> head = "Python"
>>> tail = " is fun!"
>>> head + tail
'Python is fun!'
```



### 문자열 반복: `*` 연산자

파이썬에서 다른 언어와 가장 많은 혼란을 주는 부분이 문자열을 반복할 때 사용할 수 있는 `*` 연산자이다. 아래 코드에서 `* 2`는 2회 반복의 의미지만, 곱셈의 의미와 매우 혼동될 수 있다.

``` python
>>> a = "python"
>>> a * 2
'pythonpython'
>>> "=" * 5
'=================================================='
```




### 문자열 인덱싱과 슬라이싱: `[]`

문자열 인덱싱이란 문자열에서 원하는 위치의 문자를 얻는 것이고, 슬라이싱은 부분 문자열을 얻는 것이다. 파이썬도 C/C++과 마찬가지로 인덱스는 0부터 시작하고, 역순의 경우 '-'를 사용한다.  따라서, 마지막 문자는 뒤에서 첫번째 문자로서 인덱스로 `-1`이고, 뒤에서 2번째 문자의 인덱스는 `-2`가 된다. 

```python
>>> a = "Hello"
>>> a[2]
'e'
>>> a[-1]
'o'
>>> a[-2]
'l'
>>> a[0] + a[-1]
'Ho'
```



`[]`는 문자뿐만 아니라 문자열 추출하는 슬라이싱 (Slicing) 으로도 사용된다. 여기서 주의할 점은 [0:2] = [0,1]만이 포함된 list가 생성된다. 따라서, 2는 포함되지 않는다. `:` 뒤의 stop값이 주어지지 않는 경우 step=-1이 되고, `:`의 앞에 start가 생략된 경우 0부터 추출한다.

```python
>>> a[0:2] + 'y'
'Hey'
>>> a[:2] + 'y'
'Hey'
>>> a[1:]
'ello'
>>> a[:]
'Hello'
```



지금까지 프로그래밍을 위해 가장 기본적인 자료형인 숫자형과 문자형을 알아보았다. 지금까지 소개한 것보다 더 많은 내용들이 있지만, 앞으로 배워가면서 소개하도록 하겠다.
