1. **Visual Studio 2022 Community (무료)** 설치

1. **QuestaSim(또는 Questa)** 설치 경로 확인

> ※ Questa가 64비트라면 VS도 **x64 컴파일러**로 빌드해야 합니다. (아래 배치파일이 x64로 설정)

# 1) 예제 파일

아래 2개 파일을 같은 폴더(예: `C:\work\dpi_demo`)에 저장하세요.

**(A) SystemVerilog: `test.sv`**

```
// test.sv
module test;
    import "DPI-C" function int add_two(int a, int b);

    initial begin
        int result;
        result = add_two(3, 5);
        $display("Result from DPI C function = %0d", result);
        $finish;
    end
endmodule
```

**(B) C 코드: `add.c`**  *(C++로 빌드할 경우 extern "C" 주의 → 아래 주석 참고)*

```
// add.c
#include <stdio.h>
// #include "svdpi.h" // SV 타입(svOpenArrayHandle 등) 쓸 때만 필요. 단순 int 입출력은 불필요.

int add_two(int a, int b) {
    return a + b;
}

/*
만약 C++(.cpp)로 빌드한다면 함수 선언에 링키지 지정 필요:
extern "C" int add_two(int a, int b) { return a + b; }
*/
```

# 2) 한 번에 빌드/실행하는 배치파일

아래 내용을 `run_dpi_questasim.bat` 로 저장한 뒤, **우클릭 → 관리자 권한으로 실행**(권장) 하세요.
 (경로는 환경에 맞게 수정)

```
@echo off
setlocal

:: === [수정 필요] 설치 경로 ===
set "VS_DEV_CMD=C:\Program Files\Microsoft Visual Studio\2022\Community\Common7\Tools\VsDevCmd.bat"
set "QUESTA_HOME=C:\intelFPGA_pro\24.2\questa_fe\win64"   :: 또는 C:\MentorGraphics\QuestaSim 등

:: === 작업 폴더 ===
set "WORKDIR=%~dp0"   :: 배치파일과 같은 폴더
cd /d "%WORKDIR%"

echo.
echo [1/5] VS2022 개발 환경(x64) 설정...
call "%VS_DEV_CMD%" -arch=amd64 >nul
if errorlevel 1 (
  echo VS 개발 환경 설정 실패. VS 경로(VS_DEV_CMD) 확인 필요.
  exit /b 1
)

echo.
echo [2/5] C 코드(DLL) 빌드...
:: /LD: DLL 생성, /Fe: 출력 파일명, /MD: 런타임 링크(기본)
cl /nologo /O2 /LD add.c /Fe:tdpi.dll
if errorlevel 1 (
  echo DLL 빌드 실패.
  exit /b 1
)

echo.
echo [3/5] QuestaSim 환경 설정...
set "PATH=%QUESTA_HOME%\win64;%QUESTA_HOME%\bin;%PATH%"
set "LM_LICENSE_FILE=%LM_LICENSE_FILE%"  :: 필요시 라이선스 설정

echo.
echo [4/5] SV 컴파일(vlog)...
vlog -sv test.sv
if errorlevel 1 (
  echo vlog 실패.
  exit /b 1
)

echo.
echo [5/5] 시뮬레이션 실행(vsim) 및 DLL 로드...
:: -sv_lib 뒤에는 확장자(.dll) 없이 베이스이름만!
vsim -c -sv_lib "%WORKDIR%\tdpi" work.test -do "run -all; quit"
:: GUI로 보고 싶다면 위 라인 대신 아래 사용:
:: vsim -sv_lib "%WORKDIR%\tdpi" work.test

endlocal
```

**실행 결과 예시**

```
# Loading sv_std.std
# Loading work.test
# Result from DPI C function = 8
# ** Note: $finish    : test.sv(9)
```

# 4) 자주 발생하는 이슈 & 해결

- **(아키텍처 불일치)**
  - 에러: *“Unable to load library … is not a valid Win32 application”*
  - 원인: Questa가 64비트인데 DLL을 32비트로 빌드함
  - 해결: VS 개발자 프롬프트를 **amd64(x64)** 로 열고 빌드
- **(이름 장식 문제, C++ 빌드 시 LNK2019 등)**
  - 원인: C++에서 빌드했는데 `extern "C"` 미지정 → 심볼 이름 변형
  - 해결: `extern "C"` 로 함수 선언/정의 래핑
- **(DLL 경로 문제)**
  - vsim의 `-sv_lib`는 **확장자 없이 베이스명**
  - 상대경로/절대경로 모두 가능. 빈칸/한글 경로는 따옴표로 감싸기
- **(svdpi.h 필요 시)**
  - SV 배열/문자열/핸들(svOpenArrayHandle 등) 사용하면 include 필요:
     `#include "svdpi.h"` (경로: `$(QUESTA_HOME)\include`)
  - cl에 포함 경로 추가:
     `cl /I "%QUESTA_HOME%\include" /LD mydpi.c /Fe:mydpi.dll`
- **(라이선스/실행 오류)**
  - `vsim -version` 으로 동작 확인
  - `LM_LICENSE_FILE` 환경변수 설정 점검
