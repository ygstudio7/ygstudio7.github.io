# 네트워크 드라이브 암호 확인 방법





윈도우에 저장된 암호를 확인하는 방법은, Windows Credentials Manager를 실행해서 확인할 수 있습니다.

제어판을 실행합니다.

![image-20211209161443408](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-12-09-컴퓨터-공유폴더 암호 확인.assets\image-20211209161443408.png)



사용자 계정을 선택합니다.

![image-20211209161550018](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-12-09-컴퓨터-공유폴더 암호 확인.assets\image-20211209161550018.png)



자격 증명 관리자를 선택합니다.

![image-20211209161623985](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-12-09-컴퓨터-공유폴더 암호 확인.assets\image-20211209161623985.png)

자격 증명 관리자가 열리면, 주로 두 개의 탭이 표시됩니다. 

웹 자격 증명 섹션은 모든 브라우저 암호를 호스팅해서, 다양한 웹 사이트에 로그인할 때 사용하는 비밀번호를 저장합니다.

Windows 자격 증명 섹션은 NAS 드라이브 암호 등을 저장합니다.
