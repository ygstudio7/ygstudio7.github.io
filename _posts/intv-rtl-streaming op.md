# Streaming operator



## Question

logic [7:0] a,b,c; assign b = {<<a}; assign c = {>>a}; 과 

logic [0:7] a,b,c; assign b = {<<a}; assign c = {>>a}; 은 어떤 차이가 있지?



1. `assign b = {<<{a}};` (비트 반전)

`{<< }` 연산자는 비트의 순서를 **오른쪽 끝에서 왼쪽 끝 순서**로 재배치합니다.

- **동작:** `a`의 가장 오른쪽 비트(인덱스 7)를 `b`의 가장 왼쪽(인덱스 0)에 넣고, 그다음 비트를 차례로 채웁니다.
- **결과:** 비트 순서가 완전히 거꾸로 뒤집힙니다 (**Bit Reversal**).
- **예시:**
  - `a = 8'b1100_0000;` (a[0]=1, a[1]=1, a[2..7]=0)
  - `b = 8'b0000_0011;` (b[0..5]=0, b[6]=1, b[7]=1)
- `assign c = {>>{a}};` (그대로 복사)

`{>> }` 연산자는 비트의 순서를 **왼쪽 끝에서 오른쪽 끝 순서**로 읽어서 채웁니다.

- **동작:** `a`의 가장 왼쪽 비트(인덱스 0)부터 시작해서 순서대로 `c`에 채웁니다.
- **결과:** 원본 `a`와 똑같은 값이 `c`에 들어갑니다.
- **예시:**
  - `a = 8'b1100_0000;`
  - `c = 8'b1100_0000;`

------

💡 주의할 점: `[0:7]`과 `[7:0]`의 차이

SystemVerilog의 스트리밍 연산자는 인덱스 번호(`0`이냐 `7`이냐)를 보지 않고, 오직 **데이터의 왼쪽(Left)과 오른쪽(Right)**이라는 물리적 위치만 봅니다.

- `logic [7:0] a;` 일 때: 왼쪽은 인덱스 `7`, 오른쪽은 인덱스 `0`입니다.
- `logic [0:7] a;` 일 때: 왼쪽은 인덱스 `0`, 오른쪽은 인덱스 `7`입니다.



# Summary

어떤 방식으로 선언하든 **`{<<{a}}`는 항상 전체 비트를 거울처럼 뒤집고, `{>>{a}}`는 항상 그대로 유지**한다는 사실은 변하지 않습니다.

요약

- **`b = {<<{a}}`**: 비트 순서가 **역전**됨. (예: `11000000` -> `00000011`)
- **`c = {>>{a}}`**: 비트 순서가 **유지**됨. (예: `11000000` -> `11000000`)
