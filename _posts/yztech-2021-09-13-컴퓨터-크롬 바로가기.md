# 크롬 사용자 계정 바로가기 만들기



# 방법 1: 자동 생성 방법

크롬은 사용자 계정마다 바로가기를 만들 수 있습니다. 

요즘같이 covid-19로 인해 온 가족이 집에 있는 시간이 많고, 

컴퓨터를 같이 사용하는 시간이 많은 경우에는.

가족 구성원 별로 크롬 브라우저의 바로가기를 따로 만들면,

북마크, 방문기록, 비밀번호등을 서로 다르게 구성할 수 있기 때문에 매우 편리합니다.



크롬을 열고, 바로가기를 만들고자 하는 사용자 계정으로 변경한후, 우측 빨간색으로 표시된 `연필 모양 아이콘`을 클릭합니다.

![image-20210913113138861](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\images\image-20210913113138861.png)





`설정`에서 `프로필 맞춤설정` 화면이 표시되면, 가장 아래 부분에서 `바탕화면 바로가기 만들기`를 찾아서 활성화시키면, 바탕화면에 해당 사용자의 바로가기 (`.Ink`) 가 생성됩니다. 

![image-20210913113316949](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\images\image-20210913113316949.png)



# 방법 2: 수동 생성 방법

수동 생성 방법은 바탕화면에서 오른쪽 마우스 버튼을 클릭한 후, `새로 만들기` > `바로가기`를 통해 만드는 것입니다.

![image-20210913115453829](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\images\image-20210913115453829.png)



먼저 `찾아보기`를 눌러서 구글 크롬의 실행파일을 찾습니다.

기본적으로 크롬은 아래 위치에 설치됩니다. 

```
C:\Program Files (x86)\Google\Chrome\Application\chrome.exe
```

![image-20210913115700505](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\images\image-20210913115700505.png)

![image-20210913115618649](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\images\image-20210913115618649.png)

바로가기 이름을 입력합니다. 

여러 계정 혼재시 Google ID를 이름으로 입력하면 쉽게 구분할 수 있습니다.

![image-20210913115833325](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\images\image-20210913115833325.png)



바탕화면에, `oliver_twist`라는 이름의 크롬 바로가기가 생성되었습니다.

![image-20210913115915365](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\images\image-20210913115915365.png)



아이콘을 선택후, 우측 마우스를 누라고, `속성`을 선택합니다.

![image-20210913115955102](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\images\image-20210913115955102.png)



이제 `대상` 항목에 아래와 같이 Google의 사용자 계정을 추가하면, 바로가기 실행시 해당 사용자 계정으로 들어가게 됩니다.

```
"C:\Program Files (x86)\Google\Chrome\Application\chrome.exe" --profile-directory="oliver_twist 1"
```



설정가능한 사용자 계정들은 본인 계정의 다음 폴더에서 `Profile`로 시작하는 이름들로 확인할 수 있습니다.

```
C:\Users\<본인계정이름>\AppData\Local\Google\Chrome\User Data
```

![image-20210913120603828](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\images\image-20210913120603828.png)

`Opera` 웹 브라우저의 경우, 계정과 폴더가 일치해서 쉽게 확인할 수 있지만, Chrome에서는 profile 폴더마다 들어가서, `Google Profile Picture.png`파일들을 확인해봐야 하는 불편이 있습니다.
