## **Visual Studio Code에서 코드 편집**

### **기본 편집 기능**

VS Code는 강력한 코드 편집 기능을 제공합니다:

- **구문 강조 표시 및 테마 지원:** 다양한 프로그래밍 언어를 위한 구문 강조 표시와 사용자 정의 가능한 테마.
- **자동 완성(IntelliSense):** 코드 입력 시 지능형 코드 제안 및 자동 완성.
- **코드 탐색:** 정의로 이동, 참조 찾기, 심볼 검색 등의 탐색 기능.

------

### **다중 커서 및 선택**

- **다중 커서 추가:** `Alt + 클릭` 또는 `Ctrl + Alt + 아래/위 화살표`(Windows/Linux), `Option + 클릭`(Mac).
- **같은 단어 선택:** `Ctrl + D`(Windows/Linux), `Cmd + D`(Mac).
- **전체 일치 선택:** `Shift + Ctrl + L`(Windows/Linux), `Shift + Cmd + L`(Mac).

------

### **코드 서식 지정**

- **자동 서식 지정:** `Shift + Alt + F`(Windows/Linux), `Shift + Option + F`(Mac).
- **서식 지정 옵션 설정:** `settings.json`에서 사용자 정의 가능.

------

### **스니펫 사용**

- **사전 정의된 코드 스니펫:** 특정 언어의 코드 템플릿 사용.
- **사용자 정의 스니펫:** `.code-snippets` 파일을 통해 사용자 정의 가능.

------

### **언어별 기능 확장**

- 특정 언어 지원 확장은 **확장 마켓플레이스**에서 설치 가능.

------

### **단축키 사용자 정의**

- **단축키 보기/수정:** `File` → `Preferences` → `Keyboard Shortcuts`.
- **JSON 파일 편집:** 직접 `keybindings.json` 수정 가능.

------
