# 15) “power of 2” 판별

### 개념

- **정수 x>0**에 대해 `(x & (x-1)) == 0`.
- **이유**: 2의 거듭제곱은 **단 하나의 1비트**만 셋.

### 3분 답변

2의 제곱은: x = 2^k = 0001000b  //1이 1개만 있음

x-1은 0001000b -1 = 0000111b // 하위가 모두 1이 됨

따라서, 2의 제곱수의 경우 x & (x-1) = 0과 같게 된다.

```verilog
function automatic logic is_pow2 #(int W=32) (input logic [W-1:0] x);
  return (x != '0) && ((x & (x - 1)) == '0);
endfunction
```
