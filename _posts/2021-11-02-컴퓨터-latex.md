miktex의 설치



구글에서 mktex를 검색하고, 제일 먼저 나오는 miktex 홈페이지에 들어가서 원하는 OS에 해당하는 버전을 다운로드한다.

![image-20211102121800097](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-11-02-컴퓨터-latex.assets\image-20211102121800097.png)



윈도우 OS의 경우 아래 화면과 같이 설치파일을 다운로드한다.

![image-20211102121935247](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-11-02-컴퓨터-latex.assets\image-20211102121935247.png)



다운로드한 설치파일을 실행하면, 설치 조건에 관련된 내용들이 나오고, [v] I accept the MikTex copying conditions에 체크한 후, `다음` 버튼을 누른다.

![image-20211102122541487](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-11-02-컴퓨터-latex.assets\image-20211102122541487.png)

설치범위 선택에서는 설치및 유지보수가 간단한 `(o) Install MikTeX only for me`를 선택하고, `다음`버튼을 누른다.

![image-20211102122626123](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-11-02-컴퓨터-latex.assets\image-20211102122626123.png)

설치 폴더를 선택하고, `다음` 버튼을 누른다. 이 폴더는 나중에 Aurora같은 프로그램을 사용할 경우 경로 설정에 필요하므로, 따로 위치를 기억해 두어야 한다.

![image-20211102123124138](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-11-02-컴퓨터-latex.assets\image-20211102123124138.png)



설정에서는 페이지 크기를 A4와 Letter중 선택하고, 설치되지 않은 패키지를 새로 설치할때 먼저 물어보도록 설정하고, `다음` 버튼을 누른다.

![image-20211102122935014](E:\_ygkim\_Doc\_future\_work\github pages\ygstudio7\ygstudio7.github.io\_posts\2021-11-02-컴퓨터-latex.assets\image-20211102122935014.png)



최종 설정을 확인하고, `Start` 버튼을 누른다.

설치가 완료되면, 신규 업데이트할 지 확인한다. `다음`버튼을 누른다.
