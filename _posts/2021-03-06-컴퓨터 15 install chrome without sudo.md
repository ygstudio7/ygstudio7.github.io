# How to install chrome ubuntu without sudo



reference: https://askubuntu.com/questions/198014/install-google-chrome-ubuntu-12-04-without-sudo



#### Download the stable version of `google-chrome` from the [home page](https://www.google.com/chrome/)



![image-20210306150823610](e:\_ygkim\_Doc\_future\\_work\github pages\ygstudio7\ygstudio7.github.io\images\image-20210306150823610.png)



#### Extract the downloaded package to a location of your choice

`e.g:` with .deb package: `dpkg -x google-chrom... path/to/google-chrome`

```bash
//Project/ubox/

dpkg -x g
```





Run `google-chrome` from `path/to/google-chrome/opt/google/chrome/google-chrome`



Follow this step if you wish to open `google-chrome` from your status bar. When `google-chrome` is open right click on the icon at the status bar then select `lock to launcher` option.
