# tar 압축시 특정 파일을 제외하는 방법



## 1.



**tar**을 사용하여 파일을 압축할 때 특정 파일을 제외하고 싶다면 **–exclude** 옵션을 활용할 수 있습니다. 여러 가지 방법으로 특정 파일이나 디렉토리를 제외할 수 있습니다. 아래 예시를 참고해보세요:

1. **특정 파일 제외하기**:

   - 아래 명령은 `file1.txt`을 제외하고 `source_dir` 디렉토리를 `file.tar.gz`로 압축합니다.

   ```bash
   tar -zcvf file.tar.gz source_dir --exclude="file1.txt"
   ```

   

2. **파일 확장자로 제외하기**:

   - 아래 명령은 `.log` 확장자를 가진 파일을 제외하고 압축합니다.

   ```bash
   tar -zcvf file.tar.gz source_dir --exclude="*.log"
   ```

   

3. **여러 파일 제외하기**:

   - 아래 명령은 `.log`와 `.attach`로 끝나는 파일, 그리고 `folder_name` 디렉토리를 제외합니다.

   ```bash
   tar -zcvf file.tar.gz source_dir --exclude="*.log" --exclude="*.attach*" --exclude="./folder_name"
   ```

   

위 방법을 활용하여 원하는 파일을 제외하고 효율적으로 압축할 수 있습니다. 📦🚀





## 2.

**tar**를 이용하여 파일을 압축할 때 특정 파일을 제외하는 방법은 다음과 같습니다:

1. **-X (대문자) 옵션 사용하기**:

   - **-X**는 **exclude list** 옵션으로, 파일에 정의된 경로는 **tar로 묶이지 않습니다**.

   - 먼저, 제외하고 싶은 디렉토리나 파일 목록을 정의한 **list 파일**을 생성합니다. 이 파일에는 디렉토리나 파일의 경로를 행으로 구분하여 입력합니다.

   - 예시: 만약

      

     ```
     /home/test1/tmp/
     ```

      

     경로에 존재하는 파일

      

     ```
     a
     ```

     와

      

     ```
     b
     ```

     를 제외하고 싶다면,

      

     ```
     exlist
     ```

      

     파일에 다음과 같이 입력합니다:

     ```
     /home/test1/tmp/a
     /home/test1/tmp/b
     ```

     

   - tar

      

     압축 명령을 사용합니다:

     ```
     tar -X /home/test1/tmp/exlist -cvpf test.tar /home/test1/tmp/*
     ```

     

   - 리스트에 포함된 파일은 **tar 로그에서 excluded로 표시**되며 묶이지 않습니다. 만약 디렉토리라면 하위 디렉토리는 자동적으로 제외되어 묶이지 않습니다.

2. **–exclude 옵션 사용하기**:

   - 다음과 같이

      

     –exclude

      

     옵션을 사용하여 특정 파일이나 디렉토리를 제외할 수 있습니다:

     ```
     tar -cvfz 파일명.tar 압축파일경로 --exclude=제외할경로명
     ```

     

   - 예시:

      

     ```
     .settings
     ```

      

     디렉토리를 제외하고

      

     ```
     test
     ```

      

     폴더를 tar로 묶고 싶다면:

     ```
     tar cvf test.tar --exclude ".settings" test
     ```

     

이렇게 하면 특정 파일을 제외하고 **tar 압축**할 수 있습니다. 😊



# tar 압축시 특정 폴더 제외

**tar**를 사용하여 특정 폴더를 제외하고 압축하는 방법은 다음과 같습니다:

1. **–exclude 옵션 사용하기**:

   - **–exclude** 옵션을 사용하여 특정 폴더를 제외할 수 있습니다.

   - 예시: 만약

      

     ```
     test
     ```

      

     폴더를 압축하면서

      

     ```
     test/bbb
     ```

      

     폴더를 제외하고 싶다면 다음과 같이 명령을 실행합니다:

     ```
     tar cvf test.tar --exclude "test/bbb" test
     ```

     

2. **-X (대문자) 옵션 사용하기**:

   - **-X**는 **exclude list** 옵션으로, 파일에 정의된 경로는 **tar로 묶이지 않습니다**.

   - 먼저, 제외하고 싶은 디렉토리나 파일 목록을 정의한 **list 파일**을 생성합니다. 이 파일에는 디렉토리나 파일의 경로를 행으로 구분하여 입력합니다.

   - 예시: 만약

      

     ```
     /home/test1/tmp/
     ```

      

     경로에 존재하는 파일

      

     ```
     a
     ```

     와

      

     ```
     b
     ```

     를 제외하고 싶다면,

      

     ```
     exlist
     ```

      

     파일에 다음과 같이 입력합니다:

     ```
     /home/test1/tmp/a
     /home/test1/tmp/b
     ```

     

   - tar

      

     압축 명령을 사용합니다:
