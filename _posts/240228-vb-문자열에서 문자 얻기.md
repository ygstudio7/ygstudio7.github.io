# Visual Basic에서 문자열의 문자에 액세스



[이 예제에서는 Chars[\]](https://learn.microsoft.com/en-us/dotnet/api/system.string.chars) 속성을 사용하여 문자열의 지정된 위치에 있는 문자에 액세스하는 방법을 보여줍니다 .



## 예

때로는 문자열의 문자와 문자열 내 해당 문자의 위치에 대한 데이터를 갖는 것이 유용할 수 있습니다. 문자열을 문자 배열( `Char`인스턴스)로 생각할 수 있습니다. [Chars[\]](https://learn.microsoft.com/en-us/dotnet/api/system.string.chars) 속성을 통해 해당 문자의 인덱스를 참조하여 특정 문자를 검색할 수 있습니다 .

VB

```vb
    Dim myString As String = "ABCDE"
    Dim myChar As Char

    ' Assign "D" to myChar.
    myChar = myString.Chars(3)
```

[Chars[\]](https://learn.microsoft.com/en-us/dotnet/api/system.string.chars)`index` 속성 의 매개 변수는 0 부터 시작합니다.



## 강력한 프로그래밍

Chars [[\]](https://learn.microsoft.com/en-us/dotnet/api/system.string.chars) 속성은 지정된 위치의 문자를 반환합니다. 그러나 일부 유니코드 문자는 두 개 이상의 문자로 표시될 수 있습니다. 유니코드 문자를 사용하는 방법에 대한 자세한 내용은 [방법: 문자열을 문자 배열로 변환을](https://learn.microsoft.com/en-us/dotnet/visual-basic/programming-guide/language-features/strings/how-to-convert-a-string-to-an-array-of-characters) 참조하세요 .

Chars [[\]](https://learn.microsoft.com/en-us/dotnet/api/system.string.chars) 속성은 매개 변수가 문자열 길이보다 크거나 같거나 0보다 작은 경우 [IndexOutOfRangeException](https://learn.microsoft.com/en-us/dotnet/api/system.indexoutofrangeexception) 예외를 발생시킵니다.`index`
