(0) os 라이브러리를 import

(1) 현재 경로를 얻는다

(2) os의 cmd명령을 사용하려면 os.system()을 사용한다. {} 를 사용하여 문자열 format을 생성 한다.

이부분은 `os.syste(`dir`)`을 사용해도 되나, 한글에서 문제가 생긴다.

(3) 결과를 저장하고자 할 때는 `os.popen'을 사용한다. read로 읽은 값을 변수에 저장한다.



```python
import os                               # (0)

path = os.getcwd()                      # (1)

os.system('cd {}'.format(os.getcwd()))  # (2)
output = os.popen('dir').read()         # (3)
print(output)
```

# cmd로 random하게 uid, vid 선정하기

참고: https://enfanthoon.tistory.com/108?category=885775


```python
import os
import random

st1 = "e:/_ygkim/ubox/ubox/st1.bat"

uid_list = ["ajbaker725","bernardbaker68","ollehbaker"]
default_list = list(range(0,26))
origami_list = [1,3,4] + [19,24]*10
english_list = [2,10] + [5]*5 + [26]*10
lego_list = [17,18,21,22,23]
skate_list = [range(10,16)]
minecraft_list = [8,6,7,20] + [25]*2
mindstorm_list = [9]*2
play_list = [100]
vid_list = default_list + origami_list + english_list + lego_list + skate_list + minecraft_list + mindstorm_list + play_list

print("uid: {}".format(uid_list))
print("vid: {}".format(vid_list))

# random choice
uid = random.choice(uid_list)
vid = random.choice(vid_list)
str = "{0} {1} {2}".format(st1,uid,vid)
print(str)
os.system(str)  # (2)
```
