# 명령 프롬프트에서 파일 내용 출력하기



도스 창에서는 `type` 명릉을 사용하여, 텍스트 파일을 화면에 출력할 수 있다. `type`뒤에 파일명을 적고 실행하면 된다.

```
> type a.txt
```



만약 경로명에 공백이 포함되어 있다면, 큰 따옴표로 묶어주면 된다.

```
> type "C:\Program Files\Java\jre\README.txt"
```



만약 파일의 내용이 너무 길 경우에는, 마우스 휠을 위쪽으로 돌려서 확인해도 되고, `| more` 옵션을 사용하면, 한페이지씩 출력해 준다. 

```
type a.txt | more
```



만약, 현제 폴더의 모든 txt 확장자를 가진 파일들의 내용을 한꺼번에 출력할 떄는 아래와 같이 입력한다.

```
type *.txt
```
