awk는 다음과 같은 조건이 만족하는 행에서 문자열 치환이 가능하다.

예를 들면, ok 이라는 문자가 포함된 행에서, here 를 there로 변경하고 싶다고 하자.

예제 파일은 다음과 같다.

```
here is ok
this is ok
here is okay
```

이 경우, 다음과 같이 ok가 포함된 행인 첫번째 행에서 here만 there로 변경되어야 한다.

2번째 행은 here이 없으므로, ok가 있어도 변경되지 않는다.

3번째 행은 문자열 전체가 ok가 아니므로 변경되지 않아야 한다.

```
there is ok
this is ok
here is okay
```



### 예제 1:

ok가 포함된 모든 행을 출력한다.

```
>awk '{if(/ok/) print}' test.txt > test1.out
> cat test1.out
here is ok
this is ok
here is okay
```



### 예제 2:

문자열이 ok인 행만 출력한다. 마지막 행은 출력되지 않는다.

```
> awk '{if(/\yok\y/) print}' test.txt > test2.out
> cat test2.out
here is ok
this is ok

```



### 예제 3:

gsub(x,y)는 x를 y로 global substitute한다.

/\yhere\y/은 here를 매칭하는 regular expression이다. 

```
>awk '{if(/\yok\y/) gsub(/\yhere\y/,"there");print}' test.txt > test3.out
>cat test3.out
there is ok
this is ok
here is okay

```
