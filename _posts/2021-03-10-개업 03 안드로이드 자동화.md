# [*] 현재 forground app 닫기

참고: https://www.sisik.eu/blog/android/adb/killing-current-foreground-app

아래와 같이 dumpsys 명령을 치면, mCurrentFocus 를 찾을 수 있다.

```cmd
> adb -s 127.0.0.1:21503 shell dumpsys window windows
...
  mCurrentFocus=Window{64015e4 u0 com.opera.browser/com.opera.android.BrowserActivity}
```

만약 위와 같이 opera browser의 경우에는 아래 명령으로 browser를 닫을 수 있다. 

```
adb -s 127.0.0.1:21503 shell am force-stop com.opera.browser
```
