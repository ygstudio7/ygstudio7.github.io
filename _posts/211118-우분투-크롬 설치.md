# ubuntu 18.04, 구글 크롬 웹 브라우저 설치하는 방법

구글 chrome은 전 세계에서 가장 널리 사용되는 웹 브라우저입니다. 

[내용] 기존 크롬 관련 블로그 참고



Chrome은 오픈 소스 웹 브라우저가 아니라서, ubuntu 저장소에 포함되지 않습니다. 

Chrome은 기본 Ubuntu 저장소에 사용할 수 있는 오픈 소스 브라우저인 Chromium을 기반으로 합니다.



오늘은 Ubuntu 18.04에 구글 Chrome 웹 브라우저를 설치하는 방법을 소개하도록 하겠습니다.

기존 16.04와 Debian, Linux Mint 등 다른 Debian 기반에서도 동일하게 진행할 수 있습니다.



# 설치

먼저 구글 Chrome을 다운로드합니다.

터미널을 열어서, wget으로 구글 Chrome의 deb 패키지를 다운로드합니다.

```bash
wget https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb
```



아래와 같이 apt를 이용하여 구글 Chrome을 설치합니다. 

```bash
sudo apt install ./google-chrome-stable_current_amd64.deb
```



# 실행

명령줄에서 Google chrome을 입력하거나, Google Chrome아이콘을 클릭해서 실행합니다.

아래와 같이 Chrome 시작 페이지가 표시됩니다.
