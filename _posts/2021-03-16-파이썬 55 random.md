# choice, sample 함수

: 참고: https://enfanthoon.tistory.com/108

choice함수는 리스트내에서 1개만 추출할 때 사용한다. 아래 코드는 [0,10) 범위내에서 1개의 숫자를 무작위로 추출한다.

```python
i = random.choice(range(0,10))
```



sample 함수는 중복되지 않은, 다수의 숫자를 생성한다. 아래 코드는 [0,10] 범위내에서 중복되지 않은 3개의 숫자를 무작위로 추출한다.

```python
i = random.choice(range(0,10),3)
```
